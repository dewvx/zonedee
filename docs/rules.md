# กฎการเทรด (สเปกที่โค้ดต้องตรงตาม)

> ที่มา: สไลด์ "ท่าไม้ตาย ริวเรน" (40 หน้า) + หนังสือ "บรา-รอน ดัชนีแห่งความเงียบ" (51 หน้า)
> สรุปและตีความเป็นกฎที่เขียนโค้ดได้ — ไฟล์ต้นฉบับไม่มีตัวเลขนิยาม ค่า default ทั้งหมดในนี้ **เราตั้งเอง** และต้องพิสูจน์ด้วย backtest
>
> สัญลักษณ์: ✅ นิยามชัด เขียนได้เลย · 🟡 เขียนได้แต่ต้องตีความ · ⚠ ยังต้องตัดสินใจ (ดูหัวข้อ "การตัดสินใจที่ค้าง") · ❌ เขียนเป็นโค้ดไม่ได้

---

## หลักการร่วม

- ทุก detector ทำงานแบบ **causal**: ที่แท่ง `i` ใช้ข้อมูลได้แค่แท่ง `0..i` ที่ปิดแล้ว
- ทุกค่าที่จูนได้ต้องอยู่ใน config (ไม่ hardcode) ชื่อค่าในตารางด้านล่างคือชื่อที่ใช้ในโค้ด
- ระยะห่าง/ความกว้างโซนวัดเป็นสัดส่วนของ **ATR(14)** เพื่อให้ใช้ได้ทั้งทอง, forex และหุ้น
- multi-timeframe: ข้อมูล TF ใหญ่ใช้ได้หลังแท่ง TF ใหญ่นั้น **ปิดแล้ว** เท่านั้น

### โซนแนวรับแนวต้าน (สำหรับแสดงบนกราฟ) ✅ Phase 3 — `core/zones/sr-zones.ts`

1. หา swing (ยืนยันแล้ว) → แต่ละ swing คือระดับราคา (high ของ swing high / low ของ swing low)
2. ระดับที่ห่างจาก center ของโซนเดิม ≤ `zoneMergeAtr × ATR` → รวมเข้าโซนนั้น (touches + 1, ขยายแถบ, center = ค่าเฉลี่ยระดับ) ไม่งั้นเปิดโซนใหม่กว้าง `zoneWidthAtr × ATR`
3. เดินทีละแท่งอัปเดตสถานะ (เริ่มเช็กแท่งถัดจากที่โซนเกิด):
   - `fresh` → `tested` เมื่อไส้เข้าโซน หรือมี swing ใหม่มารวม
   - แนวต้านถูก**ปิดทะลุขึ้น** (ตาม `breakBy`) → กลายเป็นแนวรับ สถานะ `flipped` ป้าย **RBS** · แนวรับถูกปิดทะลุลง → แนวต้าน ป้าย **SBR**
   - ถูกทะลุซ้ำหลังกลับขั้ว → ทิ้งโซน
4. ตอนแสดงผล: โซนบทบาทเดียวกันที่ซ้อนกันหรือห่างกัน ≤ `zoneMergeAtr × ATR` (ATR ของแท่งล่าสุด) รวมเป็นโซนเดียว
5. คะแนน = touches + 1 (ถ้า flipped) + 1 (ถ้ามีเนื้อเท่ากัน) + 2 × ความใหม่ (ลดครึ่งทุก 300 แท่ง)
6. เลือก `maxZones` โซนคะแนนสูงสุด **แบ่งโควต้าครึ่งเหนือ/ครึ่งใต้ราคาปัจจุบัน** (ฝั่งไหนไม่พอยกให้อีกฝั่ง)
7. `ryuMode = true` → เอาเฉพาะโซนที่มี swing ผ่านกฎ "เนื้อเท่ากัน 2 แท่ง" (ป้ายมี ●)
- config: `zoneMergeAtr = 0.3`, `zoneWidthAtr = 0.15`, `maxZones = 8`, `ryuMode = false`, `swingLength = 3`, `atrPeriod = 14`
- ข้อสังเกต: เกณฑ์เนื้อเท่ากัน (`equalTolAtr = 0.05`) บนข้อมูลจริงผ่านง่าย เพราะเช็กทั้งรอยต่อเนื้อและขอบเนื้อเท่ากัน — ถ้าโหมดริวเรนกรองแทบไม่ออก ให้ลด tolerance (D2)

## ชั้นที่ 3 — Braron

### Bo buy / Bo sell (กรอบ 3 TF)
- ในหนังสือ "อินดิเคเตอร์" คือ Moving Average period 1 (= เส้นราคา) + เครื่องมือวาดสี่เหลี่ยม → ไม่ใช่อินดิเคเตอร์จริง
- **Buy**: กรอบเขียว TF ใหญ่ → ราคาขึ้นไปทำกรอบแดง TF กลาง → ย่อลงมาทำกรอบเขียว TF เล็ก → buy, TP ที่กรอบแดง TF กลาง (หรือเก็บก่อน)
- **Sell**: กลับด้าน
- กฎจำ: ฝั่ง buy = เขียว 2 แดง 1 · ฝั่ง sell = แดง 2 เขียว 1
- ชุด TF: `M30-M15-M5` (หลัก), `H4-H1-M30`, `W1-D1-H4`, `M15-M5-M1`
- ✅ D5 (เจ้าของยืนยันจากหนังสือหน้า PDF 37–39, 18 ต.ค. 2026): กรอบคือ **โซน "เบรกแล้วรอกลับมาทดสอบ"** ไม่ใช่ช่วงพักตัว
  1. **เส้น BO** = ยอด swing high ที่ถูกเบรก (= ระดับ BOS) — ฝั่ง sell = swing low ที่ถูกเบรก
  2. **กรอบ Bo buy**: ขอบบน = high (ไส้) ของ swing high ที่ถูกเบรก · ขอบล่าง = low (ไส้) ต่ำสุดระหว่าง swing high นั้นกับแท่งที่เบรก (ฐานที่ส่งราคาขึ้นไปเบรก) · ขอบซ้าย = แท่ง swing high · ลากไปทางขวาจนกว่าจะหมดอายุ
  3. **กรอบ Bo sell**: กลับด้าน — ขอบล่าง = low ของ swing low ที่ถูกเบรก · ขอบบน = high สูงสุดระหว่าง swing low นั้นกับแท่งที่เบรก
  4. **หมดอายุ**: ราคาปิดทะลุขอบล่าง (buy) / ขอบบน (sell)
  5. การเบรกใช้กฎเดียวกับ BOS (D3: ปิดทะลุ) — กรอบเกิด ณ แท่งที่เบรก (confirmIndex)
- config: `boBreakBy = breakBy` (ใช้ค่าเดียวกับ BOS)

### sk Fibo + buy1 / buy2 ✅
1. หา BOS ให้เจอก่อน
2. ลาก Fibo Retracement จาก swing low → swing high ของขาที่ทำ BOS (ขาลงกลับด้าน)
3. **buy1** = โซน 0.5–0.618 · **buy2** = โซน 0.786–0.886 (หนังสือเขียนสลับ 76.8/88.6 กับ 76–86 → ใช้ค่ามาตรฐาน)
4. SL: ใต้กรอบ / ใต้ swing low (ถ้าเล่น TF ใหญ่ SL ก็ใหญ่ตาม)
5. TP: Fibo Extension 1.618–2.0
- ต้องใช้คู่กับ Bo buy/Bo sell ("ไม่งั้นจะโดน SL")
- levels ที่ใช้: `0, 0.236, 0.382, 0.5, 0.618, 0.786, 0.886, 1, 1.618, 1.809, 2`

### Money Management ✅ Phase 5 — `core/risk/position.ts`
- R:R ขั้นต่ำ `minRR = 2`
- เสี่ยงต่อไม้ `riskPct = 1` (ช่วง 1–2%)
- `lot = (balance × riskPct / 100) / (slPips × pipValuePerLot)`
- ขนาด lot: Standard 1.00 = 100,000 หน่วย · Mini 0.10 · Micro 0.01 · (ทอง: 1 lot = 100 ออนซ์ — ⚠ เช็กกับสเปกสัญญาของ XM)
- แผนสำรอง: แพ้แผน 1 มีโซนที่ 2 (buy1 → buy2) ถ้าพลาดทั้งคู่ "ควรหยุด"
- โค้ดจริง: `lossPerLot = (ระยะ SL ÷ tickSize + spreadPoints × point ÷ tickSize) × tickValue` · lot ปัดลงตาม `volumeStep` · ต่ำกว่า `volumeMin` → 0 lot พร้อมบอกความเสี่ยงถ้าใช้ขั้นต่ำ
- margin: `quote` (XXXUSD, ทอง) = lots × contract × ราคา ÷ leverage · `base` (USDJPY) = lots × contract ÷ leverage · หุ้น leverage 1
- สเปกสัญญาดึงจาก MT5 (`mt5_export.py --info`) — tickValue/contract/lot ขั้นต่ำ/leverage/ยอดเงินของบัญชีจริง
- เทสต์ใช้ตัวอย่างในหนังสือ: ทุน $1,000 เสี่ยง 2% SL 20 pips EURUSD → 0.10 lot ✅

## Backtest ✅ Phase 6 — `core/backtest/*`

| เรื่อง | กฎที่ engine ใช้ |
|---|---|
| ราคา | ราคาในข้อมูล = **bid** · ซื้อที่ ask (= bid + spread) · short ปิดด้วยการซื้อ จึงเทียบ SL/TP กับ ask |
| market | เข้าที่ราคาเปิดของแท่ง**ถัดจาก**แท่งสัญญาณ (สัญญาณรู้ผลตอนแท่งปิด) |
| limit | รอราคามาถึงภายใน `expiryBars` แท่ง (ค่าเริ่มต้น 30–50) · ราคาไปถึง TP ก่อนได้เข้า = ยกเลิก · เปิดกระโดดเลยราคา limit = ได้ราคาเปิด (ดีกว่า) · แท่งที่ limit ถูกจับไม่นับ TP (ไม่รู้ลำดับ) |
| gap | ราคาเปิดกระโดดข้าม SL/TP → ออกที่ราคาเปิด (SL อาจเสียเกิน 1R) |
| SL+TP แท่งเดียว | ดูแท่ง M1 ในช่วงนั้นว่าอันไหนโดนก่อน · ไม่มี M1 / ยังแยกไม่ได้ → SL (D10) |
| ทีละไม้ | ถือได้ทีละสถานะ · **limit ที่ยังรอ "จองช่อง" ไว้จนถึงแท่งที่ยกเลิก/หมดอายุ** — ห้ามย้อนไปรับสัญญาณที่มาระหว่างนั้น (ตอนนั้นยังไม่รู้ว่า limit จะไม่ถูกจับ = แอบดูอนาคต · เจอบั๊กนี้ตอนทดสอบกับ random walk แล้วแก้แล้ว) |
| ปิดตามเวลา | `maxBarsInTrade` (0 = ไม่จำกัด) · ข้อมูลหมด = ปิดที่ราคาปิดแท่งสุดท้าย (eod) |
| หน่วย | ผลเป็น **R** (1R = ระยะ entry→SL รวม spread) — เทียบข้ามตลาดได้ · เงินคิดแบบเสี่ยงคงที่ `riskPct`% ของยอดปัจจุบัน (ทบต้น ไม่สน lot ขั้นต่ำ) |
| out-of-sample | แบ่งตามเวลา 70 / 30 (`oosFraction = 0.3`) — จูนค่าโดยดูแค่ช่วงแรก แล้วเช็กว่าช่วงหลังยังกำไร |
| เทียบเข้าสุ่ม | สุ่มจุดเข้า + ทิศ จำนวนเท่ากับเทรดของท่า ใช้ระยะ SL/TP ชุดเดียวกัน จำลองด้วย engine เดียวกัน 200 รอบ → percentile ของ expectancy ท่านี้ (≥ 95 = น่าสนใจ) |
| ตรวจ engine | บน random walk ล้วน (ไม่มีทางทำกำไรได้) ทุกท่าได้ expectancy ≈ 0 (30 ชุด × 7 ท่า) · จำลองทีละสัญญาณเทียบกับเส้นทางราคาละเอียดได้ผลตรงกัน |

เกณฑ์ก่อนเชื่อท่าไหน (หน้า Backtest สรุปให้อัตโนมัติ): **≥ 100 เทรด · กำไรช่วง out-of-sample · ชนะการเข้าแบบสุ่ม ≥ 95%**

## หุ้น US ✅ Phase 10–11 — `core/scan/*`

**ตัวสแกนหุ้นซิ่ง** (`scanStock`, แท่ง D1) — คัดกรองเท่านั้น ไม่ใช่สัญญาณซื้อ
| สัญญาณ | นิยาม | ค่าเริ่มต้น |
|---|---|---|
| Vol พุ่ง | volume วันล่าสุด ÷ ค่าเฉลี่ย `volLookback` วันก่อนหน้า ≥ `minRelVolume` | 20 วัน, 2 เท่า |
| Gap | (open วันนี้ − close เมื่อวาน) ÷ close เมื่อวาน ≥ `minGapPct` | 4% |
| ทะลุกรอบ | close วันนี้ > high สูงสุดของ `breakoutLookback` วันก่อนหน้า | 20 วัน |
| BOS ขึ้น | `detectStructure` มีเบรกขาขึ้นใน `bosWithinBars` แท่งล่าสุด | 3 แท่ง |
| ตัวกรอง | ราคา `minPrice`–`maxPrice` และมูลค่าซื้อขายเฉลี่ย/วัน ≥ `minAvgDollarVolume` | $0.5–$50, $1M |

**Watchlist ลงทุน** (`watchMetrics`) — ผลตอบแทนนับตามปฏิทิน (1w = 7, 1m = 30, 3m = 91, 1y = 365 วัน; YTD จากราคาปิดวันสุดท้ายของปีก่อน), high/low 52 สัปดาห์, SMA 50/200, RSI 14 (Wilder, คิดจาก 300 แท่งล่าสุด)
